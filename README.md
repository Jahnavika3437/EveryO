## 🛠️ Troubleshooting Tips

### Download is slow
Try pausing other downloads or using a wired internet connection. Check your available storage space.

### Installation fails
Ensure your Windows is up to date. Temporarily disable antivirus during installation, then re-enable it. Run the installer as administrator.

### Application won't start
Restart your computer. Verify you have the latest graphics drivers installed from your computer manufacturer's website.

### GPU not detected
Make sure you have an NVIDIA graphics card. Download and install the latest CUDA drivers from NVIDIA's website. Then restart EveryO.
